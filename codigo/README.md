# Código do Projeto

O código presente nessa pasta está organizados em três seções principais: a raiz, a pasta pages e a pasta assets. 

* Na raiz da pasta codigo estão localizados os arquivos principais do código do projeto objetivando facilitar o acesso aos mesmos. Esses arquivos são o README.md, o arquivo atual, e o index.html, que é a página de acesso inicial do site.

* Dentro da pasta pages, estão presentes os códigos das páginas do site. Essas páginas estão ligadas entre si pelos botões de navegação do menu.

* Dentro da pasta Assets há outras quatro seções: A raiz, a pasta CSS, a pasta Images e a pasta Scripts.
  - Na raiz de Assets estão presentes os arquivos JSON do projeto, que armazenam os dados salvos no site.
  - Na pasta CSS estão presentes os arquivos CSS de estilização das páginas do site.
  - Na pasta Images estão presentes os arquivos de imagem do site.
  - Na pasta Scripts estão presentes os arquivos JS do site, sendo responsáveis pela dinamização das páginas presentes na pasta pages.
